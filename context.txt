§1  ONE-LINER
--------------------------------------------------------------------------------
Online compiler + Monaco editor for Python / C / C++ / Java / JavaScript
(Node.js), shipped in TWO modes from one React renderer: a Web app and an
Electron DESKTOP IDE (real filesystem + integrated terminal behind a secure IPC
bridge). MERN monorepo + an Express API that proxies to a batch execution
provider, plus a local-interactive WebSocket path for real stdin on the
developer's own machine. The full /ide shell runs in both modes.

§12  WHAT STILL NEEDS WORK / WATCH-LIST
--------------------------------------------------------------------------------
  • Compiled-language prompt flush caveat (SERVER pipe runner only): printf
    without trailing "\n" may not appear before the child blocks on a pipe
    read. A real PTY fixes it — and one now exists on DESKTOP via node-pty,
    but it must be rebuilt for Electron (needs VS Build Tools); without the
    rebuild the /ide terminal shows an honest "unavailable" state. The web
    /editor interactive path still uses the pipe runner. See memory.txt §7/D5.
  • Live lint currently covers SYNTAX only. Deeper semantic linting
    (e.g. pylint/checkstyle/cppcheck) is not wired.
  • No "Problems" panel — markers only surface as squiggles + hover.
  • Installer only supports winget + choco. Adding scoop/apt/brew would
    extend detectPackageManager + a per-OS package-id map.
  • Public Pages hero + About copy is admin-editable but the default
    seeds live in client/src/content/siteContent.js — keep in sync with
    server/src/config/siteContent.js.
  • Piston public tier is whitelist-only; a self-hosted Piston is the
    upgrade path if you need more languages.

§13  HOW TO TAKE A LOOK IN 10 SECONDS
--------------------------------------------------------------------------------
  From a fresh shell:
    cd e:\StackAmit-IDE
    npm run dev
  Then open the full IDE at http://localhost:5173/ide
  (legacy single-file workspace still at /editor)
  Or run the marketing pages: http://localhost:5173/ · /about · /contact
  Admin: http://localhost:5173/login (credentials in server/.env).
  Desktop (Electron) — needs the backend for execution, then:
    cd client; npm run dev:electron     # or from root: npm run dev:desktop
  Package a Windows installer:
    cd client; npm run dist:win          # → client/release/*.exe
